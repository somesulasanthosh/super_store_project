# super_store_project


An end-to-end Data Analytics project that analyzes Superstore sales data using SQL and Power BI to generate business insights through interactive dashboards.

---

## 📌 Project Overview

This project focuses on analyzing retail sales data to identify sales trends, profit performance, customer behavior, and regional performance. The dashboard enables stakeholders to make data-driven decisions using interactive visualizations and KPIs.

---

## 🎯 Objectives

- Analyze sales and profit performance
- Identify top-performing products and categories
- Track regional and customer segment performance
- Monitor monthly sales trends
- Discover loss-making products and regions
- Build an interactive dashboard for business users

---

## 🛠️ Technologies Used

- SQL Server
- Power BI
- Power Query
- DAX
- Data modelling

---

## 📂 Dataset

The dataset contains Superstore retail sales information including:

- Order ID
- Order Date
- Customer
- Segment
- Region
- State

- Product Name
- Sales
- Quantity
- Discount

---

## 📌 Key Insights

- Technology category generated the highest sales.
- West region contributed the highest revenue.
- Some products showed high sales but negative profit due to heavy discounts.
- Consumer segment generated the maximum sales.
- Sales peaked during the year-end months.
- Office Supplies had consistent sales across regions.
